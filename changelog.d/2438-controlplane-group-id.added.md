A Raft control plane records a random group id when its metadata group forms. A broker with durable storage stores the group id it first served under in `controlplane_group` in its data directory and refuses to start, or to apply the catalog, when the control plane names another one, or when its directory holds data from before the record: the control plane was recreated and the broker must be wiped. New `GET /v1/cluster/identity`; stream and cache snapshots carry an optional `group_id` (#2438).
