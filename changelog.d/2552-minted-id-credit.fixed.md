- A wiped data directory's new storage id, or one written in place of a corrupt id file, keeps its readmission credit across a clean restart once the run that wrote it has made a dated registration. The start records the new id in `minted-id`, that run's registration binds the record, and later starts credit it while the control plane names the id and the node has registered only from this directory since. A run that stops before its first dated registration loses the credit, which costs a readmission only (#2552).
