- A broker whose Raft restore gate rotated its storage id mid-run now keeps readmission credit for a lost copy at the next start. The directory records its last rotation in `last-rotation`, bound to the node's registration at that moment (`registered_at_millis` and incarnation, kept in the new `registered-at` record). The id counts as minted while the control plane names either id and every registration since came from this directory; a node deleted and added again, or one that registered from another directory or an older release in between, gets no credit (#2546).
