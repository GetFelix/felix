A broker whose data directory was checked against a control plane with no metadata group (the in-memory one) now stops when a snapshot or change-feed page names a group, instead of applying it. Before, a broker that started from its view after the operator moved it to a new Raft control plane applied that control plane's catalog over data it never knew about. The next start asks the control plane, which refuses a directory holding data unless the group adopts existing data. A group that adopts the directory replaces its `controlplane_group_none` mark (#2438).
