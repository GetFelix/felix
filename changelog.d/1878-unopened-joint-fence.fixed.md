Under `joint_fence`, a failover now also fences the set an earlier joint fence was leaving when that fence may never have opened: the failing-over broker's log keeps the old set beside its own and holds no record written at its own set's generation (#1878). Before, it fenced only the control plane's set before the route and the log's own set, so after a set change whose fence never opened it could open on majorities that held none of the copies of a write acknowledged before the change. `joint_fence` cannot be finalized by any release yet.
