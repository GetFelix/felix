- A cache watch resuming on a Raft cache shard is now replayed the changes it missed, deletes included, as on the hybrid engine, rather than answered with `resnapshot` and every key's current value. Each member keeps its latest applied changes (up to 4096, or 1 MiB of keys and values, per shard); a resume from before the oldest kept change, a snapshot install or a restart still resnapshots (#3006).
