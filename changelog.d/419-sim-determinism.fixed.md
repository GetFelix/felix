A simulator seed built with `--cfg tokio_unstable` now replays exactly: the same seed gives the same history event for event. The maps storage, the broker, the broker service, replication and the control plane keep hash with a seeded `ahash` under the simulator (random keys otherwise), the control plane's incarnations and the cache's expiry stamps read the shared clock, and data directories no longer carry the process id. `task sim:determinism` runs each seed twice and fails on the first event that differs; CI runs it on seeds 1 to 20 (#419).
