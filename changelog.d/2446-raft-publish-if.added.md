`publish_if` works on a stream shard that runs on Raft (`FELIX_SHARD_ENGINE=raft`). Each replica decides the condition from the index the entry lands at: the record when it is the expected offset, a blank entry otherwise. So on Raft a refused `publish_if` consumes one offset, a gap readers skip, and `offset_mismatch` names the tail past it; on the default engine a refusal consumes none. A conditional publish on Raft carries one record, and either answer comes at the commit. The conditional entry is Raft wire layout 6, so a member on an older build refuses it instead of storing it unconditionally (#2446).
