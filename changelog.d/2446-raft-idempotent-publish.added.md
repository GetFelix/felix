- A durable stream shard on Raft (`FELIX_SHARD_ENGINE=raft`) takes idempotent publishes (#2446).
  The producer id and sequence are stored in each entry, so every member's log knows each producer's place. A batch sent again after a leader change is answered with the offsets it first got and is not written a second time. The refusals (`sequence_gap`, `unknown_producer`, `sequence_expired`, `sequence_reused`) are the hybrid's. An idempotent batch of more than one record is refused on a Raft shard (`invalid_request`, not retryable) with nothing written; send each record as its own batch (#2524).
