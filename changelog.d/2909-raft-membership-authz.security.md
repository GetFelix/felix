A broker with a valid internal certificate can no longer take part in a Raft group it is not a member of. Each member refuses a vote, append, snapshot or other Raft message whose sender is not in its own membership, so an outsider cannot take leadership or truncate acknowledged entries. The control plane takes a group's reported voters only from a leader its Raft target names, or, between a set change and its new target, from a broker still in the set. A removed broker can no longer report itself back into the brokers a new copy listens to (metadata level 47).
