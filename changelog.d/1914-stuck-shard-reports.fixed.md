More shards that a live leader could not serve now get reported to the control plane, or recover on their own, instead of staying down (#1914). A follower that took a newly elected leader's fence stands again once that leader says it is no longer standing, or after `FELIX_ELECTION_DEFER_FOR_MS` (60 s by default) if it never opened, and that leader stops refusing pre-votes after the same time. One follower's newer ballot no longer ends a working leader's readers; only a newer assignment does. An open that fails with an error such as an I/O error now reports the generation refused once, so the control plane names it again, and so does a fence that meets a newer replica set.
