The control plane can start a Raft group's next epoch from a re-form plan in one compare-and-swap write (`StartReformedEpoch`, metadata level 50), refused for another stream incarnation, another epoch or a floor raised since the plan. Re-form plans now cover Raft cache shards, and brokers answer their surveys from the cache store's root (#2978).
Applying a re-form plan runs a stop round, a compare against the plan the operator read, the epoch write and a start round on the survey channel; a broker stops a copy only when its member does not lead, and syncs `raft-stopped` before it answers.
`felixctl raft reform apply <plan> [--accept-loss <shard>]` and `POST /v1/raft/reform/plans/{plan_id}/apply` (`node.manage` on `cluster:*`) apply a plan; a request dropped during the epoch write no longer leaves the shard at `writing`. Brokers do not start the new epoch yet, so an applied shard waits at `starting`.
