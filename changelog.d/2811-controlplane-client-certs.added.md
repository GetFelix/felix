The control-plane API can require client certificates. `FELIX_CONTROLPLANE_TLS_CLIENT_CA` (config file `tls.client_ca_path`) refuses the TLS handshake to a caller without a certificate from that CA, and `FELIX_CONTROLPLANE_TLS_CLIENT_CERT_BIND_SUBJECT` (`tls.bind_subject`) also requires each bearer token to name the principal the certificate was issued to. Brokers present a certificate with `FELIX_CONTROLPLANE_CLIENT_CERT` and `FELIX_CONTROLPLANE_CLIENT_KEY`, felixctl with `--controlplane-client-cert-file` and `--controlplane-client-key-file`. Both are off by default, so existing deployments are unchanged.
