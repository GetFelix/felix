A shard on Raft now carries an offset floor (`raft_floor`): the highest committed log id its leaders reported, with the stream incarnation, reform epoch, index and term, at metadata level 38. Brokers report it through `POST /v1/nodes/{node_id}/raft-floors`, one batch per broker. The floor only rises, is kept per stream incarnation and reform epoch, survives snapshots and export/import, and a placement write at the same incarnation keeps it. A bad entry is skipped without failing the batch; a control-plane member below level 38 refuses the whole batch with 409. Nothing reads the floor yet (#2402).
