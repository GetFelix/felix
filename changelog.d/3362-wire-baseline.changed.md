- 0.8 has a baseline feature set and no fallbacks for peers without it (#3362). A 0.7 client cannot connect to a 0.8 broker: the broker refuses an `auth` that does not offer every baseline flag and feature with the new `below_baseline` error code, and never answers with a plain `ok`. A 0.8 client refuses an `auth_ok` that lacks the broker baseline, so it will not connect to a 0.7-era broker. Error codes, ack offsets and detail, the shard-moved and stream-deleted frames, and `not_leader` redirects are always sent, the Rust client no longer falls back to JSON for acked, keyed or idempotent publishes, and a plain publish on a pipelining stream is answered on completion. Alpha: there are no shims, and the bit lists are in `docs/protocol.md` under "0.8 baseline".
