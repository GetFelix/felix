A broker no longer loses its lease during a disk stall. Registration and heartbeats now run on a thread and runtime of their own, so a filesystem journal stall that blocks every worker of the broker's runtime no longer stops lease renewal and gets the broker marked down (#1942). A broker whose main runtime runs nothing for 10 s still stops renewing, so a hung broker's shards fail over as before. Opening a stream shard's log and recording where its leadership begins now run on the blocking pool instead of a runtime worker.
