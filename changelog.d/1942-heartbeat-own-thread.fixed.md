A broker no longer loses its lease during a disk stall. Registration and heartbeats now run on a thread and runtime of their own, so a filesystem journal stall that blocks every worker of the broker's runtime no longer stops lease renewal and gets the broker marked down (#1942). Opening a shard's log and recording where its leadership begins now run on the blocking pool instead of a runtime worker, so a bulk create's fsyncs no longer hold up the rest of the broker.
