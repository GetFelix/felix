A learner added to a re-formed stream shard now catches up, so the shard can return to its replication factor. The re-form's gap snapshot carries no records, so the learner first pulls the records below the gap from one voter that offers it, checks each against the base, stages them and adopts them whole, then installs the snapshot. This works for a stream trimmed before its re-form too. Until it holds the base it is not promoted, does not vote, serves no reads and counts toward no commit. A learner that holds its base and still cannot install logs why and counts `felix_broker_raft_held_base_refusals_total`, and pulls again a bounded number of times.

A copy started in a re-formed epoch, or holding a base it never installed, no longer takes a new copy id at its next open: the stopped member's last batched log mark could land over the start's lowered mark, and an adopted base raised the mark to records Raft never saw, so the open read the log as below its mark.

A re-form survey reads a copy holding a base it never installed as blank, current or kept, so a plan no longer names it as the source a start then refuses every time.
