A replication factor 1 Raft shard in a cluster re-forms itself after a relaxed crash rotated its only copy, with no operator command. The broker plans and stops the copy, the control plane records the next epoch in one checked command (`POST /v1/nodes/{node_id}/reform/alone`, metadata level 55, fleet feature `raft_alone_reform`, which a new cluster finalizes), and the copy starts from the recorded seed. Every synced record is kept and offsets start above every offset given out before. `OnCommit` never takes the path, a group that is not alone on its broker is refused, a directory restored from before an earlier re-form is not stopped or started, and until the fleet finalizes the feature the shard stays not ready for an operator's re-form (#3001).
