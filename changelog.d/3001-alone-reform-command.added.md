The control plane can record the next epoch of a replication factor 1 Raft group on its broker's word (`POST /v1/nodes/{node_id}/reform/alone`, metadata level 55, fleet feature `raft_alone_reform`, which a new cluster finalizes). The same apply checks that the group is alone on the broker, with no set change or move in flight, and answers a repeated request with the recorded shard instead of a second epoch. Brokers do not send it yet (#3001).
