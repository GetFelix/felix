Starting without the control plane (`FELIX_START_WITHOUT_CONTROLPLANE`): a data directory restored from an older copy no longer starts from its control-plane view and votes on its old ballots. Every start now writes a run witness to `/dev/shm`, and a start from the view needs the witness to name the directory as the last start left it, in the same boot. A restored directory, a reboot, or a new machine or pod waits for the control plane instead. Platforms without `/dev/shm` never start from the view.
