A shard that switched to Raft now carries the Raft copy id each broker in its set reported (`raft_copy_ids`) and the target they make (`raft_target`: a counter and the members), at metadata level 36. Brokers report ids through `POST /v1/nodes/{node_id}/raft-copy-id`. The counter rises only when the members change, survives a control-plane leader change, and a restore brings back the backup's counter under a raised placement incarnation. A target change is refused, and the assignment feeds leave the target out, while any registered broker has not acknowledged the placement incarnation; the feeds send it as `target` with `version: {incarnation, counter}`. Brokers do not send ids or use targets yet (#2235).
