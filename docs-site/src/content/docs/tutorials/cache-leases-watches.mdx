import { Tabs, TabItem } from '@astrojs/starlight/components';

You will use a Felix cache for three things. First you store a value that
expires on its own. Then you build a lease, a name that only one process holds
at a time, with a conditional write, and use its version as a fencing token.
Last you watch a set of keys and print each change as it happens.

A cache is a set of keys with values, optional expiry times, and a version on
every value. Unlike a stream, it keeps the latest value per key, and a watch
tells you when one changes. See [Cache](/features/cache/) for the full model.

## Prerequisites

A running broker and the environment variables from the
[tutorials overview](/tutorials/overview/#set-up-once), and the client for your
language. The steps show Rust, Python, TypeScript and C#, and the C version is
one program at the end.

Conditional writes are in the Rust, C# and C clients. The Python and
TypeScript bindings do not have them yet, so the lease step has no tab for
those two and their programs have no `lease` mode.

## 1. Create the cache

```bash
docker compose run --rm felixctl cache create tutorial-cache
```

Use `felixctl cache create tutorial-cache` if you installed it. With these
defaults the cache is not replicated, and the leader acknowledges a write alone.
A lease you rely on in production belongs on a
cache created with `--replication 3 --consistency quorum`, so that a claim a
broker acknowledged survives losing that broker. See
[Leases, locks and idempotency](/use-cases/leases-and-locks/#what-consistency-level-gives-what).

## 2. Connect, and store a value that expires

The program takes a mode: `ttl`, `lease <name>`, `watch`, `set <key> <value>` or
`delete <key>`. The first stores a value with a five second time to live,
reads it, waits, and reads it again.

```rust
    let roots = Arc::new(root_store_from_pem_file(&ca_file)?);

    let later = client.cache_get(TENANT, NAMESPACE, CACHE, "greeting").await?;
    println!("six seconds later: {later:?}");
    Ok(())
```

## 3. Watch for changes

A watch pushes each change to a set of keys: one key, or every key that starts
with a prefix. A change is a new value or, when the value is absent, a
delete. This watch follows keys that start with `status:` and starts from now.

Two things to handle are in the loop. A watch that falls behind is ended by the
broker, and it says where to watch again from so that no change is missed.
A shard that moves to another broker is followed for you, and the watch tells
you it happened.

```rust
use anyhow::bail;
use felix_client::{CacheWatchFilter, CacheWatchItem};

async fn watch(client: &Arc<ClusterClient>) -> Result<()> {
    let mut watch = client
        .watch_cache(TENANT, NAMESPACE, CACHE, CacheWatchFilter::Prefix("status:".into()), None)
        .await?;
    println!("watching status:*");
    while let Some(item) = watch.recv().await {
        match item {
            CacheWatchItem::Change(change) => match change.value {
                Some(value) => println!("{} = {}", change.key, String::from_utf8_lossy(&value)),
                None => println!("{} deleted", change.key),
            },
            CacheWatchItem::Lagged { resume_from } => {
                bail!("fell behind; watch again from offset {resume_from}")
            }
            CacheWatchItem::ShardMoved(_) => println!("the shard moved; the watch follows it"),
        }
    }
    Ok(())
}

async fn set(client: &ClusterClient, key: &str, value: &str) -> Result<()> {
    client
        .cache_put(TENANT, NAMESPACE, CACHE, key, Bytes::copy_from_slice(value.as_bytes()), None)
        .await
}

async fn delete(client: &ClusterClient, key: &str) -> Result<()> {
    let removed = client.cache_delete(TENANT, NAMESPACE, CACHE, key).await?;
    println!("{}", if removed.is_some() { "deleted" } else { "there was nothing to delete" });
    Ok(())
}
```

```ts
  const changes = await client.watchCache(TENANT, NAMESPACE, CACHE, undefined, "status:");
  try {
    console.log("watching status:*");
    for (;;) {
      const item = await changes.recv();
      if (item === null) return;
      if (item.laggedResumeFrom !== null) {
```

## 4. Take a lease

Several workers run the same job, and exactly one should at a time. The job is
named by a cache key, and holding the lease means holding the key.

A conditional write claims it. `Absent` writes only if the key has no live
entry, and the check and the write are one atomic step, so two workers racing
for the key cannot both win. The write carries a TTL, so a holder that dies
loses the lease on its own. A refusal is an answer (`applied` is false), not an
error.

The answer to a claim that applied carries the key's version. A version is the
log offset of the write, so it only grows, across renewals, restarts and
compaction. That makes it a fencing token. A worker passes it along with
everything it does as the lease holder, and the system it writes to remembers
the highest token it has seen and refuses a lower one. Without that, a worker
that stalls past its TTL, say in a long pause, would wake up and write after the
lease passed to someone else.

The holder renews with `Version(token)`, so a renewal fails if the lease has
since changed hands, and releases with a delete at that version for the same
reason. A worker that does not hold the lease watches the key and tries again
when the lease is released or expires, or after one TTL, whichever comes first.
The expired entry is deleted by the broker, so the watch hears about it, up to
about a second after the TTL.

<Tabs syncKey="lang">
<TabItem label="Rust">

```rust
use felix_client::CacheCondition;

const LEASE_KEY: &str = "lease:report";
const LEASE_TTL_MS: u64 = 10_000;

async fn lease(client: &Arc<ClusterClient>, name: &str) -> Result<()> {
    loop {
        let claim = client
            .cache_put_if(
                TENANT, NAMESPACE, CACHE, LEASE_KEY,
                Bytes::copy_from_slice(name.as_bytes()),
                Some(LEASE_TTL_MS),
                CacheCondition::Absent,
            )
            .await?;
        if claim.applied {
            let token = claim.version.context("the broker did not report a version to fence with")?;
            return hold(client, name, token).await;
        }
        println!("{name}: the lease is taken, waiting");
        wait_for_release(client).await?;
    }
}

async fn hold(client: &ClusterClient, name: &str, mut token: u64) -> Result<()> {
    println!("{name}: holds the lease, fencing token {token}");
    for round in 1..=3 {
        // Do a unit of work here, passing `token` to whatever it writes.
        tokio::time::sleep(Duration::from_millis(LEASE_TTL_MS / 3)).await;

        let renewed = client
            .cache_put_if(
                TENANT, NAMESPACE, CACHE, LEASE_KEY,
                Bytes::copy_from_slice(name.as_bytes()),
                Some(LEASE_TTL_MS),
                CacheCondition::Version(token),
            )
            .await?;
        match renewed.version {
            Some(version) if renewed.applied => token = version,
            _ => bail!("{name}: lost the lease; stop working"),
        }
        println!("{name}: renewed (round {round}), fencing token {token}");
    }

    let released = client.cache_delete_if(TENANT, NAMESPACE, CACHE, LEASE_KEY, token).await?;
    println!("{name}: released ({})", if released.applied { "ok" } else { "it had already moved on" });
    Ok(())
}

// Returns when the lease is deleted, or after one TTL.
async fn wait_for_release(client: &Arc<ClusterClient>) -> Result<()> {
    let mut watch = client
        .watch_cache(TENANT, NAMESPACE, CACHE, CacheWatchFilter::Key(LEASE_KEY.into()), None)
        .await?;
    let deleted = async {
        while let Some(item) = watch.recv().await {
            if matches!(item, CacheWatchItem::Change(ref change) if change.value.is_none()) {
                return;
            }
        }
    };
    // A timeout is expected when the holder keeps renewing, so it is not an error.
    let _ = tokio::time::timeout(Duration::from_millis(LEASE_TTL_MS), deleted).await;
    Ok(())
}
```

```csharp
static async Task LeaseAsync(FelixCache cache, string name, CancellationToken ct)
{
    var me = Encoding.UTF8.GetBytes(name);
    var ttl = TimeSpan.FromSeconds(LeaseTtlSeconds);
    while (true)
    {
        var claim = await cache.PutIfAbsentAsync(LeaseKey, me, ttl, ct);
        if (claim.Applied)
        {
            var token = claim.Version
                ?? throw new InvalidOperationException("the broker did not report a version to fence with");
            await HoldAsync(cache, name, me, token, ct);
            return;
        }
        Console.WriteLine($"{name}: the lease is taken, waiting");
        await WaitForReleaseAsync(cache, ct);
    }
}

static async Task HoldAsync(FelixCache cache, string name, byte[] me, long token, CancellationToken ct)
{
    var ttl = TimeSpan.FromSeconds(LeaseTtlSeconds);
    Console.WriteLine($"{name}: holds the lease, fencing token {token}");
    for (var round = 1; round <= 3; round++)
    {
        // Do a unit of work here, passing `token` to whatever it writes.
        await Task.Delay(ttl / 3, ct);

        var renewed = await cache.PutIfVersionAsync(LeaseKey, me, token, ttl, ct);
        if (!renewed.Applied || renewed.Version is not { } next)
        {
            throw new InvalidOperationException($"{name}: lost the lease; stop working");
        }
        token = next;
        Console.WriteLine($"{name}: renewed (round {round}), fencing token {token}");
    }

    var released = await cache.DeleteIfVersionAsync(LeaseKey, token, ct);
    Console.WriteLine($"{name}: released ({(released.Applied ? "ok" : "it had already moved on")})");
}

// Returns when the lease is deleted, or after one TTL.
static async Task WaitForReleaseAsync(FelixCache cache, CancellationToken ct)
{
    await using var watch = await cache.WatchKeyAsync(LeaseKey, cancellationToken: ct);
    var deadline = DateTime.UtcNow.AddSeconds(LeaseTtlSeconds);
    while (DateTime.UtcNow < deadline)
    {
        var item = await watch.ReadAsync(deadline - DateTime.UtcNow, ct);
        if (item is null || item.IsDelete)
        {
            return;
        }
    }
}
```

## What you should see

The TTL mode shows the value and then its absence:

```text
right after the put: Some(b"hello")
six seconds later: None
```

Other languages print the value in their own way. For the watch, start
`watch` in one terminal and change keys from another:

```text
$ cache set status:api up
$ cache set status:worker degraded
$ cache delete status:api
```

```text
watching status:*
status:api = up
status:worker = degraded
status:api deleted
```

A key without the `status:` prefix produces nothing, because the watch filters on
the broker.

For the lease, run `lease a` and then, quickly, `lease b` in another terminal.
Your version numbers will differ. They only grow:

```text
a: holds the lease, fencing token 12
a: renewed (round 1), fencing token 14
a: renewed (round 2), fencing token 15
a: renewed (round 3), fencing token 17
a: released (ok)
```

```text
b: the lease is taken, waiting
b: holds the lease, fencing token 19
b: renewed (round 1), fencing token 21
...
```

`b` sat on a watch while `a` held the lease and took over as soon as `a`
released it. To see expiry instead, stop `a` with Ctrl-C partway through. `b`
takes over when the lease's TTL passes, at most ten seconds after `a`'s last
renewal, and its token is higher than any `a` held.

## C

Each C call returns at once and reports to a callback, so this program wraps
each one in a `waiter` that blocks until the callback has run. It has the same
modes as above. Values and keys handed to a callback are valid only while it
runs, so the callbacks copy what the program needs.

```c
#define _POSIX_C_SOURCE 200809L

#include <pthread.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>

#include "felix.h"

#define TENANT "dev"
#define NAMESPACE "default"
#define CACHE "tutorial-cache"
#define LEASE_KEY "lease:report"
#define LEASE_TTL_MS 10000

struct waiter {
    pthread_mutex_t mu;
    pthread_cond_t cv;
    bool done;
    FelixStatus status;
    void *handle;
    bool found;
    bool applied;
    bool has_version;
    uint64_t version;
    int kind;
    bool has_value;
    char key[128];
    char value[128];
    char message[256];
};

static void finish(struct waiter *w, FelixStatus status, const char *message, void *handle) {
    pthread_mutex_lock(&w->mu);
    w->done = true;
    w->status = status;
    w->handle = handle;
    snprintf(w->message, sizeof w->message, "%s", message ? message : "");
    pthread_cond_signal(&w->cv);
    pthread_mutex_unlock(&w->mu);
}

/* A refused call never runs its callback, so its error comes from the thread. */
static FelixStatus wait_for(struct waiter *w, FelixStatus started) {
    if (started != FELIX_STATUS_OK) {
        snprintf(w->message, sizeof w->message, "%s", felix_last_error_message());
        return started;
    }
    pthread_mutex_lock(&w->mu);
    while (!w->done) pthread_cond_wait(&w->cv, &w->mu);
    w->done = false;
    FelixStatus status = w->status;
    pthread_mutex_unlock(&w->mu);
    return status;
}

static void copy_text(char *to, size_t cap, const void *from, size_t len) {
    size_t n = len < cap - 1 ? len : cap - 1;
    if (n > 0) memcpy(to, from, n);
    to[n] = '\0';
}

static void on_connect(void *user_data, FelixStatus status, const char *message,
                       FelixClient *client) {
    finish(user_data, status, message, client);
}

static void on_done(void *user_data, FelixStatus status, const char *message) {
    finish(user_data, status, message, NULL);
}

static void on_value(void *user_data, FelixStatus status, const char *message, bool found,
                     const uint8_t *value, size_t len) {
    struct waiter *w = user_data;
    w->found = status == FELIX_STATUS_OK && found;
    if (w->found) copy_text(w->value, sizeof w->value, value, len);
    finish(w, status, message, NULL);
}

static void on_condition(void *user_data, FelixStatus status, const char *message,
                         bool applied, bool has_version, uint64_t version) {
    struct waiter *w = user_data;
    w->applied = applied;
    w->has_version = has_version;
    w->version = version;
    finish(w, status, message, NULL);
}

static void on_watch_open(void *user_data, FelixStatus status, const char *message,
                          FelixCacheWatch *watch) {
    finish(user_data, status, message, watch);
}

static void on_watch_item(void *user_data, FelixStatus status, const char *message,
                          const FelixWatchItem *item) {
    struct waiter *w = user_data;
    if (status == FELIX_STATUS_OK && item) {
        w->kind = item->kind;
        w->has_value = item->has_value;
        copy_text(w->key, sizeof w->key, item->key, item->key_len);
        copy_text(w->value, sizeof w->value, item->value, item->value_len);
    }
    finish(w, status, message, NULL);
}

static int ttl(const FelixClient *client, struct waiter *w) {
    static const uint8_t hello[] = "hello";
    FelixStatus status = wait_for(
        w, felix_client_cache_put(client, TENANT, NAMESPACE, CACHE, "greeting", hello,
                                  sizeof hello - 1, 5000 /* ttl_ms */, NULL, on_done, w));
    if (status != FELIX_STATUS_OK) {
        fprintf(stderr, "put: %s\n", w->message);
        return 1;
    }
    for (int pass = 0; pass < 2; pass++) {
        status = wait_for(w, felix_client_cache_get(client, TENANT, NAMESPACE, CACHE, "greeting",
                                                    NULL, on_value, w));
        if (status != FELIX_STATUS_OK) {
            fprintf(stderr, "get: %s\n", w->message);
            return 1;
        }
        printf("%s: %s\n", pass == 0 ? "right after the put" : "six seconds later",
               w->found ? w->value : "(none)");
        if (pass == 0) sleep(6);
    }
    return 0;
}

static int set_key(const FelixClient *client, struct waiter *w, const char *key,
                   const char *value) {
    FelixStatus status = wait_for(
        w, felix_client_cache_put(client, TENANT, NAMESPACE, CACHE, key, (const uint8_t *)value,
                                  strlen(value), 0 /* no expiry */, NULL, on_done, w));
    if (status != FELIX_STATUS_OK) fprintf(stderr, "put: %s\n", w->message);
    return status == FELIX_STATUS_OK ? 0 : 1;
}

static int delete_key(const FelixClient *client, struct waiter *w, const char *key) {
    FelixStatus status = wait_for(
        w, felix_client_cache_delete(client, TENANT, NAMESPACE, CACHE, key, NULL, on_value, w));
    if (status != FELIX_STATUS_OK) {
        fprintf(stderr, "delete: %s\n", w->message);
        return 1;
    }
    printf("%s\n", w->found ? "deleted" : "there was nothing to delete");
    return 0;
}

static int watch_prefix(const FelixClient *client, struct waiter *w) {
    FelixStatus status = wait_for(
        w, felix_client_watch_cache(client, TENANT, NAMESPACE, CACHE, FELIX_WATCH_PREFIX,
                                    "status:", false, false, 0, NULL, on_watch_open, w));
    if (status != FELIX_STATUS_OK) {
        fprintf(stderr, "watch: %s\n", w->message);
        return 1;
    }
    FelixCacheWatch *watch = w->handle;
    int exit_code = 1;
    printf("watching status:*\n");
    for (;;) {
        status = wait_for(w, felix_cache_watch_next(watch, 30000, NULL, on_watch_item, w));
        if (status == FELIX_STATUS_TIMEOUT) continue;
        if (status == FELIX_STATUS_CLOSED) {
            exit_code = 0;
            break;
        }
        if (status != FELIX_STATUS_OK) {
            fprintf(stderr, "watch: %s\n", w->message);
            break;
        }
        if (w->kind == FELIX_WATCH_CHANGE && w->has_value) {
            printf("%s = %s\n", w->key, w->value);
        } else if (w->kind == FELIX_WATCH_CHANGE) {
            printf("%s deleted\n", w->key);
        } else if (w->kind == FELIX_WATCH_LAGGED) {
            fprintf(stderr, "fell behind; watch again\n");
            break;
        } else {
            printf("the shard moved; the watch follows it\n");
        }
    }
    felix_cache_watch_free(watch);
    return exit_code;
}

/* Returns when the lease key is deleted, or when a wait times out. */
static int wait_for_release(const FelixClient *client, struct waiter *w) {
    FelixStatus status = wait_for(
        w, felix_client_watch_cache(client, TENANT, NAMESPACE, CACHE, FELIX_WATCH_KEY,
                                    LEASE_KEY, false, false, 0, NULL, on_watch_open, w));
    if (status != FELIX_STATUS_OK) {
        fprintf(stderr, "watch: %s\n", w->message);
        return 1;
    }
    FelixCacheWatch *watch = w->handle;
    int exit_code = 0;
    for (;;) {
        status = wait_for(w, felix_cache_watch_next(watch, LEASE_TTL_MS, NULL, on_watch_item, w));
        if (status == FELIX_STATUS_TIMEOUT || status == FELIX_STATUS_CLOSED) break;
        if (status != FELIX_STATUS_OK) {
            fprintf(stderr, "watch: %s\n", w->message);
            exit_code = 1;
            break;
        }
        if (w->kind == FELIX_WATCH_CHANGE && !w->has_value) break;
    }
    felix_cache_watch_free(watch);
    return exit_code;
}

static int hold(const FelixClient *client, struct waiter *w, const char *name, uint64_t token) {
    printf("%s: holds the lease, fencing token %llu\n", name, (unsigned long long)token);
    for (int round = 1; round <= 3; round++) {
        /* Do a unit of work here, passing token to whatever it writes. */
        struct timespec pause = {LEASE_TTL_MS / 3 / 1000, (LEASE_TTL_MS / 3 % 1000) * 1000000L};
        nanosleep(&pause, NULL);

        FelixStatus status = wait_for(
            w, felix_client_cache_put_if(client, TENANT, NAMESPACE, CACHE, LEASE_KEY,
                                         (const uint8_t *)name, strlen(name), LEASE_TTL_MS,
                                         FELIX_IF_VERSION, token, NULL, on_condition, w));
        if (status != FELIX_STATUS_OK) {
            fprintf(stderr, "renew: %s\n", w->message);
            return 1;
        }
        if (!w->applied || !w->has_version) {
            fprintf(stderr, "%s: lost the lease; stop working\n", name);
            return 1;
        }
        token = w->version;
        printf("%s: renewed (round %d), fencing token %llu\n", name, round,
               (unsigned long long)token);
    }

    FelixStatus status = wait_for(
        w, felix_client_cache_delete_if(client, TENANT, NAMESPACE, CACHE, LEASE_KEY, token, NULL,
                                        on_condition, w));
    if (status != FELIX_STATUS_OK) {
        fprintf(stderr, "release: %s\n", w->message);
        return 1;
    }
    printf("%s: released (%s)\n", name, w->applied ? "ok" : "it had already moved on");
    return 0;
}

static int lease(const FelixClient *client, struct waiter *w, const char *name) {
    for (;;) {
        FelixStatus status = wait_for(
            w, felix_client_cache_put_if(client, TENANT, NAMESPACE, CACHE, LEASE_KEY,
                                         (const uint8_t *)name, strlen(name), LEASE_TTL_MS,
                                         FELIX_IF_ABSENT, 0, NULL, on_condition, w));
        if (status != FELIX_STATUS_OK) {
            fprintf(stderr, "claim: %s\n", w->message);
            return 1;
        }
        if (w->applied) {
            if (!w->has_version) {
                fprintf(stderr, "the broker did not report a version to fence with\n");
                return 1;
            }
            return hold(client, w, name, w->version);
        }
        printf("%s: the lease is taken, waiting\n", name);
        if (wait_for_release(client, w) != 0) return 1;
    }
}

int main(int argc, char **argv) {
    const char *token = getenv("FELIX_AUTH_TOKEN");
    const char *ca_file = getenv("FELIX_CA_FILE");
    const char *broker = getenv("FELIX_BROKERS");
    const char *mode = argc > 1 ? argv[1] : "";
    bool ok = (!strcmp(mode, "ttl") || !strcmp(mode, "watch")) ||
              (!strcmp(mode, "lease") && argc > 2) || (!strcmp(mode, "set") && argc > 3) ||
              (!strcmp(mode, "delete") && argc > 2);
    if (!ok) {
        fprintf(stderr, "usage: cache ttl | watch | lease <name> | set <key> <value> | delete <key>\n");
        return 1;
    }
    if (!token || !*token || !ca_file || !*ca_file) {
        fprintf(stderr, "set FELIX_AUTH_TOKEN and FELIX_CA_FILE\n");
        return 1;
    }

    struct waiter w = {.done = false};
    pthread_mutex_init(&w.mu, NULL);
    pthread_cond_init(&w.cv, NULL);
    int exit_code = 1;

    FelixStatus status = wait_for(
        &w, felix_client_connect(broker && *broker ? broker : "127.0.0.1:5000", TENANT, token,
                                 "localhost", ca_file, NULL, on_connect, &w));
    if (status != FELIX_STATUS_OK) {
        fprintf(stderr, "connect: %s\n", w.message);
    } else {
        FelixClient *client = w.handle;
        if (!strcmp(mode, "ttl")) {
            exit_code = ttl(client, &w);
        } else if (!strcmp(mode, "watch")) {
            exit_code = watch_prefix(client, &w);
        } else if (!strcmp(mode, "lease")) {
            exit_code = lease(client, &w, argv[2]);
        } else if (!strcmp(mode, "set")) {
            exit_code = set_key(client, &w, argv[2], argv[3]);
        } else {
            exit_code = delete_key(client, &w, argv[2]);
        }
        /* Every call has completed, so no callback still holds &w. */
        felix_client_free(client);
    }
    pthread_cond_destroy(&w.cv);
    pthread_mutex_destroy(&w.mu);
    return exit_code;
}
```
